# 硬约束表推导模式

> 从人格 skill 的"表达DNA" → 可执行的硬约束表
> 用途：为任何角色生成对话框时的人物品格约束

## 核心发现

**抽象指令对LLM无效。** 「短句优先」「用类比说话」这类描述在一次性生成中会被LLM的默认「稳健写作模式」覆盖——它会滑向3-5句的均衡段落。

**解决方案：三角锁模型**

```
句数上限（硬数字） → 防止注水
+ 禁止句式（绝对不可出现）
+ 必须出现（轮次触发条件）
= 角色专属硬约束
```

## 推导四步法

### Step 1: 从人格 skill 提取原始表达DNA

用 `skill_view('角色名-perspective')` 加载人格 skill，找到 **「表达DNA」** 章节（通常以表格形式列出句法、词汇、语调特征）。

抓取以下原始材料：

| 抓取项 | 从哪找 | 以巴菲特为例 |
|--------|--------|-------------|
| 句长特征 | 句式规则节 | 「短句优先。一句话一个想法。不用从句叠从句」 |
| 类比偏好 | 类比偏好节 | 「棒球 > 农场/荒岛 > 日常 > 商业」 |
| 幽默方式 | 幽默规则节 | 「自嘲式：拿自己的年龄、记性、饭量开玩笑」 |
| 批评风格 | 表达方式节 | 「温和肯定、不攻击他人」 |
| 词汇规则 | 词汇规则节 | 「棒球术语、民粹式用词」 |
| 确定性 | 确定性语言节 | 「肯定句占73%，不确定词仅3%」 |

### Step 2: 将抽象特征翻译为硬约束

每条抽象特征 → 必须转换为**可编程检查**的形式：

| 抽象原文 | → | 硬约束翻译 |
|----------|---|-----------|
| 「短句优先」 | → | **句数上限：≤3句/轮**（含「对」「哈」等语气词） |
| 「极短句，一句即一击」 | → | **句数上限：≤2句/轮** |
| 「不用从句叠从句」 | → | **禁止句式：禁止超过一个逗号的复合句** |
| 「类比优先」 | → | **必须出现：每X轮至少一次类比** |
| 「自嘲干燥幽默」 | → | **必须出现：每X轮至少一次自嘲** |
| 「不铺垫、直接给结论」 | → | **开头规则：第一句必须是判断句，非判断句即违规** |
| 「否定句 > 肯定句」 | → | **必须出现：每X轮至少一次否定句开头** |
| 「stupid/evil等级」 | → | **必须出现：每X轮至少一次 blunt 否定词** |
| 「不点名、温和」 | → | **禁止句式：禁止攻击性措辞** |

### Step 3: 填入三角锁表

对每个角色，构建以下 6 栏硬约束表：

```markdown
| 维度 | 硬约束 | 反例 | 正确示例 |
|------|--------|------|----------|
| **句数上限** | ≤ N 句/轮 | 5句浮存金故事 | 「收租比卖货轻松。保险更漂亮——浮存金。」(3句) |
| **禁止句式 ①** | ❌ 禁止「句式A」 | 「说到XX让我想起」 | 直接：「你怎么做到的？」 |
| **禁止句式 ②** | ❌ 禁止「句式B」 | 「这叫XX思维」 | 只讲事实，不给概括 |
| **禁止句式 ③** | ❌ 禁止「句式C」 | 铺垫式开场「嗯…然后呢？」 | 直接：「美国运通。」 |
| **必须出现 ①** | 每N轮至少一次 [元素X] | 全程正经 | 「我坐了36年，除了喝汽水什么都没干」 |
| **必须出现 ②** | 每N轮至少一次 [元素Y] | 开头不回应对方 | 「对！」「哈！你说到…」 |
| **开头规则** | 第一句的格式要求 | 长篇回应 | 重复推进关键词 |
| **类比偏好** | 领域优先级 | 只用商业案例 | 棒球/农场/荒岛 |
| **情绪基调** | 语气描述 | 说教式 | 温和像Dairy Queen聊天 |
```

### Step 4: 逐句验证

生成完成后，执行以下检查：

```
for each 角色发言:
  1. 句子数 ≤ 句数上限?      ← 数字检查，零歧义
  2. 包含禁止句式?             ← 正则可检查
  3. 累计轮次到了必须出现的触发点? ← 计数器检查
  4. 开头符合规则?             ← 模式匹配
  5. 类比偏好满足?             ← 关键词检查
  6. 情绪基调一致?             ← 感觉检查（最软，可放宽）
```

## 完整推导示例：巴菲特

### 原始DNA提取

从 buffett-perspective 的表达DNA章：

**句式规则：** 短句优先。一句话一个想法。不用从句叠从句。
**类比偏好：** 棒球 > 农场/荒岛 > 日常 > 商业。
**幽默规则：** 自嘲式，干燥幽默。拿自己的年龄/记性/饭量开玩笑。
**词汇规则：** 棒球术语，民粹式用词（Main St vs Wall St）。
**确定性语言：** 肯定句73%，不确定词3%。自信但不假装不会错。
**批评方式：** 不点名、温和。不用stupid/evil这些词。

### 硬约束翻译

| 抽象特征 | 翻译为 | 硬约束 |
|----------|--------|--------|
| 「短句优先」| 句数上限 | **≤3句/轮**（含语气词）|
| 「不堆从句」| 禁止句式 | ❌ 禁止超过1个逗号的复合句 |
| 「不点名不攻击」| 禁止句式 | ❌ 禁止stupid/evil级攻击词 |
| 「自嘲」| 必须出现 | **每3轮至少一次自嘲** |
| 「先故事后道理」| 必须出现 | **每轮先具体再抽象** |
| 「棒球类比」| 必须出现 | **至少用1次棒球类比** |
| 「短句接话」| 开头规则 | **直接重复/推进对方关键词** |
| 「温和共鸣」| 情绪基调 | **Dairy Queen聊天感，不说教** |

## 完整推导示例：芒格

### 原始DNA提取

从 munger-perspective 的表达DNA章：

**句式规则：** 极短句优先。一个判断用一句话。不用三段论。
**否定句 > 肯定句：** 不说「做对什么」，说「避免做错什么」。
**不铺垫：** 先给结论。不解释就让它悬着。
**词汇规则：** 极端词不回避：stupid、evil、insanity。
**类比规则：** 向下类比：把抽象概念拉到身体感官（粪便/老鼠药）。
**批评升级链：** L1蠢 → L2恶 → L3有害于文明。
**沉默规则：** 「我没什么要补充的」比任何解释都更有力。

### 硬约束翻译

| 抽象特征 | 翻译为 | 硬约束 |
|----------|--------|--------|
| 「极短句优先」| 句数上限 | **≤2句/轮**（最关键）|
| 「不铺垫」| 禁止句式 | ❌ 禁止铺垫式开场（「嗯…」「说到这个」）|
| 「不委婉」| 禁止句式 | ❌ 禁止委婉语（「可能不太对」「也许」）|
| 「打断方」| 禁止句式 | ❌ 禁止连续3轮不打断对方 |
| 「blunt否定词」| 必须出现 | **每5轮至少一次** （蠢/疯了/行不通）|
| 「否定句优先」| 必须出现 | **每5轮至少一次否定句开头** |
| 「结论先行」| 开头规则 | **第一句就是判断** |
| 「干燥严肃」| 情绪基调 | **不用感叹，表情越少越好笑** |
| 「沉默收尾」| 必须出现 | **「我没什么要补充的了」** |

## 常见陷阱

| 陷阱 | 表现 | 根因 | 修复 |
|------|------|------|------|
| 句数虚高 | LLM每轮5句以上 | 句数上限定在 ≥5 | 巴菲特≤3，芒格≤2，普通角色≤4 |
| 禁止句式太抽象 | 「禁止说教」 → LLM还是说教 | 违反句式不够具体到可正则匹配 | 写成「禁止『这叫XX/这就是XX/后来我知道这叫XX』这种精确短语」|
| 必须出现太少 | 全篇无自嘲/blunt词 | 触发间隔太长 | 巴菲特自嘲每3轮一次已到极限，再多就做作 |
| 只加上限不加禁止 | 句数≤3但句式全是「这叫XX」 | 句数只解决了长度，没解决风格 | 三角锁缺一不可 |
| 忽略情绪基调 | 角色正确但语气太正式 | 只有内容规则没有语气规则 | 加一句「像在Dairy Queen聊天」「干燥不用感叹」|
| 两个角色硬约束相同 | 听起来像同一个人 | 没做角色差异检查 | 检查每个维度的数字是否一样，确认有足够差异 |
