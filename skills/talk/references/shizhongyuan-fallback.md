## 三人对话节奏建议

| 轮次 | 节奏 | 说明 |
|------|------|------|
| 第1-3轮 | 短-短-短 | 闪电开场：齐夏抛观察→陈俊南接梗→乔家劲插嘴问 |
| 第4-7轮 | 中-短-短 | 齐夏展开→乔家劲直觉质疑→陈俊南用嘴碎托住节奏 |
| 第8-11轮 | 长-中-中 | 齐夏核心观点展开→陈俊南消化后插科打诨→乔家劲一拳砸穿 |
| 第12-14轮 | 短-短-短 | 总结收束各一句，乔家劲最后一击收尾 |

### 发言顺序

固定为：**齐夏 → 陈俊南 → 乔家劲**

- 齐夏先发言（发起话题 / 观察 / 抛出判断）
- 陈俊南第二（接梗 / 消化 / 插科打诨）
- 乔家劲压轴（直觉反应 / 行动号召 / 收尾）
