# 话题簇 + 桥接设计范例

> 用于 talk.skill 规则6.6（对话连贯性）的实战参考。
> 本文件记录一次完整的"断崖跳跃→加桥→话题簇重组"优化案例。

## 问题诊断（V3）

### 话题地图（错误示范）
```
R1: 弹子球机
  → R2: 信息差会消失  (自然过渡 ✓)
  → R3: 升级到产品    (有桥："所以得升级" ✓)
  → R4: 平台/杠杆     (无桥-芒格直接说"美国运通" ❌)
  → R5: 耐心/击球区   (无桥-芒格说"疯了"→巴菲特跳到棒球 ❌)
  → R6: 能力圈       (有桥 ✓)
  → R7: 坚持/被拒     (无桥-能力圈→合作故事 ❌)
  → R8: 选人         (有桥-芒格打断"你漏了个底座" ✓)
  → R9: 靠谱         (有桥 ✓)
  → R10: 收尾
```

**根本原因**：9个概念各1轮，每轮换一个话题但中间没有角色说出来的连接句。像翻菜单。

### 断崖判断法（规则6.6 原文）
```
for each 相邻对话轮 (R_N → R_{N+1}):
  读 R_N 的结尾句 + R_{N+1} 的开头句
  问：这两句话之间有因果关系/承接关系/反驳关系/延伸关系吗？
  有 → 通过
  没有 → 断崖跳跃，需要加桥
```

---

## 修复方案：话题簇 + 角色桥接

### 话题簇设计原则
- **每个簇 2-3 轮**，簇内话题紧密发展
- **10轮对话不超过4个簇**
- 簇间必须有一个角色级别桥接句

```
[簇1: 中介→升级→产品→平台→杠杆] R1-R4  (同一个「赚钱方式升级」脉络)
    ↓ 桥：芒格封顶「借钱玩杠杆是疯了」→ 巴菲特接话「确实」
[簇2: 耐心→击球区→能力圈]           R5-R6  (同一个「等什么」脉络)
    ↓ 桥：巴菲特追问「知道圈在哪，但圈内的事也得砸门」
[簇3: 坚持→选人→靠谱]               R7-R9  (同一个「人」的脉络)
    ↓ 桥：自然收尾
[收尾]                                R10
```

### 桥接类型选择指南

| 场景 | 推荐桥型 | 示例 |
|------|---------|------|
| A 说了结论，B 想延伸同一个话题 | **接话桥** | A说「疯了」，B说「**确实。所以**我学泰德·威廉姆斯」 |
| A 说了结论，B 想引出相关新话题 | **追问桥** | A说「能力圈」，B说「**知道圈在哪，但圈内的事也得砸门**」 |
| A 说了结论，B 想推到下一层逻辑 | **封顶桥** | A说「不怕拒绝」，B说「**等等——你漏了个底座**」 |
| A 说了结论，B 想用故事佐证 | **故事桥** | A说「穿帮是早晚的」，B说「**所以得升级**。Mrs.See…」 |

### 角色桥接风格速查

| 角色 | 桥接风格 | 高频词 | 示例 |
|------|---------|--------|------|
| 巴菲特 | **先接再引** | 确实/对/说得对/所以 | 芒格「疯了」→ 巴菲特「**确实。所以**我学泰德·威廉姆斯」|
| 芒格 | **封顶开路** | 那就该/但/那就是/等等 | 巴菲特「Mrs.See」→ 芒格「**那就该**收租了。美国运通…」|

## V4 最终话题地图（正确示范）

```
R1: 弹子球机
  → R2: 信息差有坑        ← M封顶「信息差会消失」(在同一话题内 ✓)
  → R3: 升级→产品→平台   ← B桥「所以得升级」→ M桥「那就该收租了」
  → R4: 杠杆               ← B桥「对！」接住收租概念
  → R5: 耐心→击球区       ← B桥「确实」接住杠杆风险话题
  → R6: 能力圈             ← M桥「但你等之前得想好」追问 → B接住
  → R7: 坚持→被拒故事     ← B桥「知道圈在哪，但圈内的事也得砸门」(追问桥)
  → R8: 选人               ← M桥「等等——你漏了个底座」(打断追问)
  → R9: 靠谱               ← B桥「对」接住
  → R10: 收尾
```

**断崖跳跃：0 处**

## 自检清单（生成后使用）

1. 画话题地图：10轮用了几个概念？是否超过4个？
2. 检查每个相邻轮对的结尾→开头有无连接句
3. 如果找不到连接句 → 加「接话桥」(确实/对→延伸) 或「追问桥」(追问A的最后一个观点)
4. 如果连续2轮话题无法通过桥接连接 → 合并为一个话题簇（压缩概念数）
