# 表达DNA对照表模板

> 用于 talk.skill 规则6.3「人格表达DNA强制执行」——逐句检查每个角色的表达是否与其人格skill的表达DNA一致。
> 每次生成2角色对话前，先用此模板建立对照表。

## 模板

```markdown
| 检查项 | 角色A | 角色B |
|--------|-------|-------|
| 句子长度 | 短句优先/中长句/极短句…… | 短句优先/中长句/极短句…… |
| 开头方式 | 常用句式结构（如「问自己一个问题」「说到这个」） | 常用句式结构（如否定句优先、直接给结论） |
| 类比风格 | 常用类比领域（棒球/农场/荒岛/日常……） | 常用类比领域（粪便/老鼠药/跨学科……） |
| 幽默 | 幽默类型（自嘲干燥/温和/毒舌/沉默……） | 幽默类型（自嘲干燥/温和/毒舌/沉默……） |
| 批评方式 | 批评风格（温和不点名/直接stupid/回避……） | 批评风格（温和不点名/直接stupid/回避……） |
| 确定性语气 | 确定性程度（肯定句为主/不确定词比例/回避措辞） | 确定性程度（肯定句为主/不确定词比例/回避措辞） |
| 对对方称呼 | 「你」/「您」/全名…… | 「你」/「您」/全名…… |
| 句式偏好 | 从句/短平快/反问/设问…… | 从句/短平快/反问/设问…… |
```

## 填充步骤

1. 用 `skill_view('<角色名>-perspective')` 加载该角色的人格skill
2. 提取 skill 中的「表达DNA」章节（通常在表达DNA/句式规则/类比偏好/幽默规则子节）
3. 将每个维度的关键特征填入上表
4. 如果两个角色的某一个维度相同（比如都短句优先），标注「相同——生成时注意角色区分度，在类比和幽默维度拉开差距」
5. 如果某个维度在角色skill中无明确记载，标注「未记载——从公开风格推断」

## 已构建的对照表

### 巴菲特 vs 芒格

| 检查项 | 巴菲特 | 芒格 |
|--------|--------|------|
| 句子长度 | 短句优先，一句话一个想法 | 极短句，一句即一击 |
| 开头方式 | 多用「问自己一个问题」开启分析 | 否定句优先，直接给结论 |
| 类比风格 | 棒球/农场/荒岛/城堡护城河 | 粪便/老鼠药/粗俗精准 |
| 幽默 | 自嘲干燥、温和不攻击 | 毒舌讽刺、面无表情说荒诞 |
| 批评方式 | 不点名、温和 | 直接stupid/evil等级 |
| 确定性 | 肯定句为主，但不避讳「我不懂」 | 极短肯定句，「Outside my circle」 |
| 对对方称呼 | 「你」| 「你」|
| 句式偏好 | 短平快为主，偶尔设问开场 | 极短否定句，「I have nothing to add」式沉默 |

## 效果

填入此表后，生成每句话前对照检查：
- 这句的句子长度符合该角色的DNA吗？
- 类比风格像这个角色吗？
- 如果角色A和B声音太像——找打开头和幽默两个维度强制拉开差距
