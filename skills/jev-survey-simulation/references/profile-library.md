# 画像库素材（profile library）

> 素材维度供 LLM 现场组合，不穷举。每次根据「问卷内容 + 目标人群」独立设计 6~15 个代表 profile。

## state 撰写模板

第三人称、具体、可判断。建议包含：

```
1. 基本身份: 年龄、性别（问卷相关才写）、职业/学业阶段、城市/地区（相关才写）
2. 个性倾向: MBTI 特征的行为化描述（见下），如「喜欢先计划再执行」「凭感觉做决定」
3. 典型行为: 作息、消费习惯、社交方式、娱乐偏好
4. 价值观/动机: 看重什么、担忧什么（直接决定量表题走向）
5. 生活阶段与当前情境: 问卷涉及的场景里他处于什么状态
```

反面示例（模糊）："一个比较认真的年轻人"
正面示例："一名 22 岁大四学生，机械工程专业，准备秋招，作息规律，习惯按 checklist 执行任务，
对薪酬增幅和公积金比例敏感，不排斥加班但要求明确回报，平日通过 B 站学习技术内容。"

## 职业/身份类别（常见）

在校学生（本/硕/博/职校/考研/考公）、程序员/工程师、产品经理、运营/市场/销售、
医护、教师、公务员/事业单位、金融从业、自由职业/自媒体、设计/文创、蓝领/工人、
创业者/个体户、全职主妇/夫、退休人员。

## 人生轨迹阶段

求学→应届求职→基层打拼→职业上升期→中层管理→资深/转型→退休；
可叠加特殊轨迹：二战考研、裸辞转行、副业创业、落户定居、异地恋/婚育等。

## 常见目标人群的默认比例（启发式，用户可改）

> 均为常识近似值，非精确统计；用途是给「用户未指定比例」时一个合理起点。

### 在校大学生

| 画像维 | 默认分布 |
|---|---|
| MBTI | 抽样自常见人群近似分布：S 系偏多（约 60-65%），N 系 35-40%；F 略多于 T |
| 年级 | 大一~大四均匀，硕博少量 |
| 专业 | 理工/人文/经管/艺术大致按学校构成 |
| 轨迹 | 多数常规就读；少数叠加考研/实习/学生工作 |

### 一线城市互联网从业者（25-35）

| 画像维 | 默认分布 |
|---|---|
| MBTI | 整体 N/T 占比显著高于人群均值；INTJ/INTP/ENTJ/ENTP 偏多 |
| 岗位 | 研发/产品/设计/运营/数据平衡 |
| 轨迹 | 校招 or 社招进城、996 或弹性、租房 or 已购房 |

### 中小学生家长（30-45）

| 画像维 | 默认分布 |
|---|---|
| MBTI | SJ 系偏多（ISTJ/ISFJ/ESTJ/ESFJ） |
| 职业 | 体制内/企业/个体/全职 |
| 关注 | 分数排名 vs 素质教育 vs 身心健康 三派 |

### 退休老年人（60+）

| 画像维 | 默认分布 |
|---|---|
| MBTI | S 系为主，J 多于 P |
| 轨迹 | 帮带孙辈/独居/返聘/旅游爱好 |
| 关注 | 健康、养老钱、家庭关系 |

## 组合原则

- 6~15 个 profile 覆盖人群主要构成即可，不必面面俱到（长尾由现场设计补）
- 每个 profile 的 state 必须包含**能决定量表题走向的具体信息**（价值观、担忧、情境）
- 开放题答案（open_answers）每个 profile 预置一份，语气与 state 一致
- 比例合计必须 100%；用户手填的比例优先，其次默认，最后 LLM 推定（推定需展示依据）
