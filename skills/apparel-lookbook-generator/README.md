> WorkBuddy 技能 | 技术名称 `apparel-lookbook-generator` | 面向小红书 / Pinterest 的电商穿搭图批量生成
>
> 一张服装参考图 → 6 类风格统一的种草配图（Outfit 穿搭 / Flat Lay 平铺 / 细节 / Lifestyle / 情侣搭配 / 品牌故事）

## 一句话简介

上传一张服装 / 单品参考图（或文字描述），自动生成一套**风格统一、真人实拍感、适合小红书种草**的 6 类穿搭图矩阵：搭配图、平铺图、单品细节图、场景图、社交关系图、品牌故事图。

**运行环境**：本技能在 **WorkBuddy** 中使用，依赖 WorkBuddy 内置的 ImageGen 生图能力。

## 这个技能能做什么

- 从**单张服装参考图**出发，用图生图（image-to-image）保证整套图里的衣服、配色、材质、模特高度一致——不会出现「明明是同一件衣服，每张图都不一样」。
- 自动**推导适合的场景**（不会千篇一律咖啡店）：根据风格 / 正式度 / 季节给出画廊、高级餐厅、天台酒廊、海边等候选。
- **强制完整单品清单**：参考图里每一件衣物配饰都逐项写进提示词，杜绝漏单品（比如漏掉丝袜）。
- **写实增强**：内置相机 / 镜头 / 真实肤质 / 真实面料褶皱 + 反向约束，出图更像真实摄影而非 AI 塑料感。
- 默认**中国模特 + 小红书通透高级感**视觉语言，尺寸默认 3:4（小红书），可选 2:3（Pinterest）。
- 生图前**先预览完整提示词条 + 成本**，确认后再出图，避免浪费积分。

## 核心卖点（差异化）

1. **一致性靠原图锚定**：每张图都传入同一张产品原图（image-to-image），比「靠文字描述复刻衣服」可靠得多。
2. **杜绝漏单品**：完整单品清单 + distinctive 单品精确描述，解决「丝袜没出来 / 产品货不对板」。
3. **场景由产品决定**：从产品推导场景池，告别千篇一律的咖啡店街拍。
4. **真人有质感**：写实增强 + 反向约束，专治「AI 味重、不真实」。
5. **零外部依赖**：直接用 WorkBuddy 原生 ImageGen，无需任何第三方 API / 图床账号。
6. **面向国人**：中国模特 + 小红书 ins 风，适配国内种草平台。

## 使用流程

1. 收集输入：一张服装参考图（推荐）或文字 brief；确认平台比例（默认小红书 3:4）与中国模特偏好。
2. 建立完整单品清单（逐项列出，distinctive 单品精确描述）。
3. （可选）用 vision_analyze 自动提取风格 / 配色。
4. 从产品推导 3–4 个候选场景，与用户确认。
5. 建立输出文件夹。
6. 预览 6 类提示词矩阵 + 预估积分成本，用户确认。
7. 逐张调用 ImageGen（全部图生图，按类目设定 input_fidelity）。
8. 汇总文件，给出小红书 / Pinterest 发布建议（标题 / 话题标签 / 商品链接）。

## 使用示例（用户输入）

- 「用这张图（附参考图）帮我生成一套小红书穿搭图」
- 「给这套黑色连衣裙做 flat lay + 搭配图 + 细节图」
- 「生成一组适合 Pinterest 的学院风穿搭矩阵」
- 「把这套衣服做成 6 类目的种草图」

## 默认参数

- 尺寸：小红书 1080×1440（3:4），Pinterest 1024×1536（2:3）
- 模特：中国 / 东亚女性（可改）
- 图生图强度 input_fidelity：人物 / 场景 0.75–0.85，平铺 0.78，细节 0.65–0.75
- 积分：约 5–10 / 张，全套 16 张约 80–160

## 前置条件

- 需要 WorkBuddy 原生 ImageGen 能力（已内置）
- 生成消耗积分，生图前会提示成本
- 最佳实践：提供清晰的服装 / 单品参考图以获得最佳一致性

## 注意事项 / 已知限制

- 没有参考图时无法保证跨图同人同款，会提前告知。
- 细节图是对「原产品」的放大特写，fidelity 不低于 0.65，不会变成凭空棚拍道具。
- 提示词默认英文以获得最佳生图效果，技能会自动处理。
